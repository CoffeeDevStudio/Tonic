# Changelog

## v1.0.0

First release.

- Dynamic color from the class color, dark and light, for all 13 classes.
- Harmonized semantic colors (health, power, hostile, chat, item quality); option to
  keep health unharmonized for warm classes.
- Skins: character, bags, game menu, collections, tooltips, menus, chat, unit frames,
  nameplates. Each skin can be turned off; `/tonic audit` checks them after a patch.
- Material 3 components: button, icon button, FAB, card, switch, checkbox, radio,
  slider, text field, menu, dialog, snackbar, tabs, tooltip, list.
- Options window built with Tonic components, profiles, Blizzard Settings entry,
  minimap button and addon compartment.
- `/tonic gallery` with every token and component in every state, dark and light.
